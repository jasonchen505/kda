Kernel transpose_kernel(x_ptr, y_ptr, M, N, stride_xm, stride_xn, stride_ym, stride_yn, BLOCK_M, BLOCK_N). pid_m, pid_n from 2D grid. row = pid_m*BLOCK_M + arange(BLOCK_M); col = pid_n*BLOCK_N + arange(BLOCK_N). Load x_ptr + row[:,None]*stride_xm + col[None,:]*stride_xn with mask. Store to y_ptr + col[:,None]*stride_ym + row[None,:]*stride_yn with transposed mask. run(x): y=torch.empty((N,M),dtype,device); grid=(cdiv(M,BM),cdiv(N,BN)); launch; return y.
