1. Define _rmsnorm_kernel with X, Y, W pointers, stride, N, eps, BLOCK_SIZE constexpr. 2. Each program handles one row: load row in chunks of BLOCK_SIZE, accumulate sum of squares in FP32. 3. Compute rstd = rsqrt(sum_sq / N + eps). 4. Load row again, normalize, cast to input dtype, multiply by weight, store. 5. run() allocates output, computes BLOCK_SIZE = next_power_of_2(width) capped at 1024, launches grid=(rows,).
