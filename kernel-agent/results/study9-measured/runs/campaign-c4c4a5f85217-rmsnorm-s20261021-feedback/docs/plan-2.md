Add a constexpr flag SINGLE_BLOCK to the kernel. When width <= 1024, launch with SINGLE_BLOCK=True and BLOCK_SIZE=next_power_of_2(width), using a single load for sum-of-squares and a single load for normalization. When width > 1024, use the existing loop path with BLOCK_SIZE=1024. This reduces kernel launch overhead and register pressure for small widths while preserving correctness for all shapes.
