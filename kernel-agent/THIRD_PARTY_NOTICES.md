# Third-party references

`references/triton-3.2/` contains unmodified tutorial snapshots from Triton v3.2.0,
and a manifest of extracted function excerpts. The original copyright and MIT license
are preserved in `references/triton-3.2/LICENSE`. Source URLs and both complete-file
and excerpt SHA256 values are stored in the manifest.

KDA supplies the workflow and prompt adaptation, under its documentation's CC BY 4.0
terms. Humanize supplies the installed runtime under Apache-2.0. Their repositories
and fixed commits are linked in the README and report; their source code and model
weights are not bundled here. Example-assisted agent outputs should not be presented
as evidence of unassisted or original kernel synthesis.
