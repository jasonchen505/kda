# 求职项目：本地大模型 Kernel Agent Harness

岗位：大模型算法／研究工程师、Agent Evaluation、AI for Systems。

研究的是写 Triton kernel 的 agent。复现 KDA/Humanize 路线，再通过原生本地 Chat
后端改进生成与修复；生成源码不经人工改写，独立评测器决定正确性与性能晋升。

## 核心贡献与实证

1. 合约检查清单、搜索反例、失败记忆与正确源码锚点，配合完整源码上下文打包。
2. 同起点 2×2 交叉对照：8 类任务 × 2 个种子，64 个最终结局，152 次调用。
   首轮正确：普通 12/16、清单 11/16；完整配置最终 13/16，双基线 15/16。
   同初始失败充分观察 8 对，普通修复救回 5，反例修复救回 5。
3. 动态发现 3 组 Qwen GPU，空闲准入、延迟 EWMA 调度，块内固定进程身份；
   GPU4 评测串行，预算与未知调用保留。159 项机制／证据检查通过。
4. 历史负结果引出的门槛优先选择修复，以及真实 SIGKILL 后 0 新生成调用的阶段恢复。

## 面试里怎么讲

先讲问题：模型能写代码，却未必理解输出布局，普通断言也不足以指导修复。
再讲方法：让模型显式核对合约，并提供独立评测器产生的小反例；用相同初始代码
比较两种修复，避免起点不同掩盖效果。最后给真实计数、任务聚类区间与失败案例。
不要把 64 个结局当 64 个独立任务，也不把共享算子速度当端到端模型加速。
