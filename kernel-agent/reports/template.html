五分钟看懂这个求职项目

研究工程问题：如何让一个本地 coding agent 在数值、性能和资源约束下写出可验收的 kernel，并在失败或中断后保留可信实验记录。

复现了什么

KDA 的合约、草案和计划工作流，以及 Humanize → OpenCode → 本地 Qwen 的真实生成链路。新增直连后端用于八类任务的生成／修复对照，模型源码不经人工修改。

自己改进了什么

实现合约检查清单、微型搜索诊断、失败记忆与正确源码锚点，用同初始源码的 2×2 对照检验生成和修复效果；底层支持独立评测、候选选择、持久化预算、故障恢复和动态多服务调度。

研究迭代：历史反馈对照未证明收益，促成候选选择与恢复改进。先完成生成与修复交叉对照，保留退步结果，再检验“核验审查”，发现公式核验未带来最终收益。这轮把可信数值与索引提示直接接入事务化源码修复，用同预算对照检验；失败、未知调用与原始源码一并保留。

定位：可以写入简历的 agent harness 研究工程原型。三任务集成验证为 3/3 最终正确、2/3 晋升；最新六任务反馈对照见下方。真实生成、工程测试和历史未完成实验分别计数。
